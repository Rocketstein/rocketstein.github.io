Engineering challenge

Ordering transparent geometry and particles

Alpha blending is order-dependent: the same transparent surfaces can produce different colour and opacity depending on draw order. I treated transparency as an ordering problem at multiple levels of the renderer rather than as a single pass-level fix.

  1. 01Problem

    Alpha blending is not commutative

    Standard source-over alpha blending depends on what has already been drawn. Reversing two overlapping transparent primitives changes the accumulated colour, so arbitrary submission order produces visibly incorrect results.

    Rendering consequenceTransparent geometry must be composited in a predictable back-to-front order instead of relying on depth testing alone.

  2. 02First fix

    Sort transparent sections by camera depth

    I added camera-relative depth to the transparent draw-command path so ordinary transparent sections could be rendered back-to-front while opaque rendering kept its existing ordering.

    New problemA particle system is not a single transparent surface. Particles can overlap each other inside one emitter, while multiple emitters can also overlap in depth, so section-level sorting alone is not enough.

  3. 03Final solution

    Sort at both particle and emitter level

    Active sprite and mesh particle indices are sorted per view inside each emitter. Cross-emitter priority is handled separately by stable-sorting section indices, so render order can change without mutating the physical emitter array.

    ResultThe renderer preserves the intended back-to-front ordering across ordinary transparent geometry, individual particles, and overlapping emitters while keeping simulation storage independent from presentation order.

Conclusion + trade-off

Sorting at the appropriate granularity produces visually correct alpha blending for the engine's transparent geometry and particle effects. The cost is additional per-view, per-frame CPU sorting, and depth sorting remains an approximation for mutually intersecting transparent geometry; those cases would require a more expensive order-independent transparency technique.
