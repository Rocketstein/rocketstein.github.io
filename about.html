Bio

Hello, I’m Hyungjun “Kenneth” Kim, a Mathematics and Computer Science graduate from the University of Illinois Urbana-Champaign. I’m interested in the point where low-level systems become useful creative tools and responsive gameplay.

After graduating, I completed Krafton Jungle’s Game Tech Lab, developing a custom C++ and DirectX 11 engine in rotating small teams and using it to build playable games. I later co-developed Volumetric Super Storm, an Unreal Engine plugin published on Fab, contributing to editor tooling and real-time cloud behaviour.

I’m currently studying entity-component-system architecture through an independent engine project, focusing on data ownership, system boundaries, iteration performance, and tooling.
